# Content Creation Guide

This guide covers everything you need to know about creating and organizing
content for your Scriba blog.

## Post Structure

All blog posts are Markdown files stored in the `posts/` directory. Each post
consists of two parts:

1. **YAML Frontmatter** - Metadata about the post
2. **Markdown Content** - The actual post content

### Basic Post Example

```markdown
---
title: "Hello, World!"
date: 2025-07-20
author: "Carlos"
tags: ["intro", "personal"]
status: "published"
---

# Your Post Content

Write your content here using Markdown...
```

## Frontmatter Reference

The YAML frontmatter block at the top of each post defines metadata. All fields
are processed case-sensitively.

### Required Fields

- **`title`** (string): The post title, used in HTML title tags and navigation
- **`date`** (YYYY-MM-DD): Publication date, determines URL structure and
  sorting
- **`author`** (string): Author name, displayed on post pages
- **`status`** (string): Publication status (see below)

### Optional Fields

- **`tags`** (array): List of tags for categorization
  ```yaml
  tags: ["rust", "programming", "tutorial"]
  ```
- **`excerpt`** (string): Brief summary for social sharing and previews
  ```yaml
  excerpt: "Learn the basics of Rust ownership in this beginner-friendly guide"
  ```

### Post Status Options

- **`"published"`**: Post is live and visible to all visitors
- **`"draft"`**: Post exists but won't appear on the site
- **`"scheduled"`**: Post is prepared but not yet published (manual publishing
  required)

## URL Structure

Posts are automatically assigned URLs based on their date and title:

```
/YYYY/MM/DD/slug
```

**Examples:**

- Date: `2025-07-20`, Title: `"Hello, World!"` → `/2025/07/20/hello-world`
- Date: `2025-12-01`, Title: `"My First Blog Post"` →
  `/2025/12/01/my-first-blog-post`

The slug is generated by:

1. Converting title to lowercase
2. Replacing spaces and special characters with hyphens
3. Removing consecutive hyphens

## Markdown Features

Scriba supports standard Markdown with additional features:

### Headings

```markdown
# H1 Heading

## H2 Heading

### H3 Heading
```

### Text Formatting

```markdown
**bold text** _italic text_ `inline code`
```

### Links

```markdown
[Link text](https://example.com) [Internal link](/2025/07/20/other-post)
```

### Lists

```markdown
- Unordered list item
- Another item

1. Ordered list item
2. Another item
```

### Code Blocks

Scriba includes syntax highlighting for code blocks:

````markdown
```javascript
console.log("Hello, World!");
```

```python
def hello():
    print("Hello, World!")
```

```rust
fn main() {
    println!("Hello, World!");
}
```
````

### Blockquotes

```markdown
> This is a blockquote with multiple lines
```

### Images

Place images in the `static/` directory and reference them:

```markdown
![Alt text](/image.png) ![Alt text](/images/screenshot.jpg)
```

## Content Organization

### File Naming

While the filename doesn't affect the URL, using a consistent naming pattern
helps with organization:

```
posts/
├── 2025-01-15-getting-started.md
├── 2025-02-01-advanced-features.md
├── 2025-02-15-deployment-guide.md
└── 2025-03-01-troubleshooting.md
```

**Recommended pattern:** `YYYY-MM-DD-descriptive-slug.md`

### Directory Structure

For blogs with many posts, you can organize into subdirectories:

```
posts/
├── 2025/
│   ├── 01-getting-started.md
│   ├── 02-advanced-features.md
│   └── 03-deployment.md
├── tutorials/
│   ├── 2025-01-01-rust-basics.md
│   └── 2025-01-15-rust-advanced.md
└── personal/
    └── 2025-01-20-hello-world.md
```

Scriba will find posts in any subdirectory within `posts/`.

## Writing Tips

### SEO-Friendly Posts

1. **Write descriptive titles** - They become your URL slug and page title
2. **Use excerpts** - Provide clear summaries for social sharing
3. **Structure with headings** - Use H2 and H3 tags to organize content
4. **Add relevant tags** - Help with content categorization

### Content Best Practices

1. **Front-load important information** - Put key points early in posts
2. **Use code examples** - Take advantage of syntax highlighting
3. **Write in Markdown** - Keep formatting simple and portable
4. **Test locally** - Use `deno task start` to preview before publishing

## Real Example

Here's a complete example from an actual Scriba blog:

```markdown
---
title: "Hello, World!"
date: 2025-07-20
author: "Carlos"
tags: ["intro", "personal"]
status: "published"
---

# Who is Carlos?

I'm a senior software engineer with 10 years of experience, and I've spent most
of my career as a backend and distributed systems engineer. Currently, I'm
working at Block where I focus on building the platforms that power our customer
support tooling.

## What you might find here

The content will probably be a mix of things. Sometimes I'll write about
technical deep-dives when I've spent time understanding how something works and
want to share that journey.

You might also find me exploring new technologies or concepts, sharing first
impressions and what I'm learning as I go.

---

_This blog is powered by [Scriba](https://github.com/ctorresmx/scriba), built
with Deno, Fresh, and a lot of markdown files._
```

This creates a post accessible at `/2025/07/20/hello-world` with proper metadata
and formatting.
